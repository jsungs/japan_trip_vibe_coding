# Hokkaido Journey

홋카이도 여행지를 소개하는 한국어 정적 웹사이트입니다. 순수 HTML, CSS, JavaScript로 만들었고 서버, API 키, 빌드 도구 없이 GitHub Pages에서 호스팅할 수 있습니다.

## 페이지

- `index.html` — 3초 자동 전환 슬라이드, 일본 열도 안내도, 여행지·체험·뉴스 바로가기
- `destinations.html` — 삿포로, 비에이·후라노, 하코다테, 시레토코, 도야호, 니세코
- `activities.html` — 스키, 온천, 자연 산책, 유빙, 꽃밭, 로컬 푸드
- `news.html` — 2026년 11월 6일에 확인한 지역 관광·교통 소식의 정적 요약
- `sources.html` — 정보·사진 출처와 이미지 라이선스

## GitHub Pages 게시

1. 이 폴더의 파일을 GitHub 저장소 루트에 올립니다.
2. 저장소의 **Settings → Pages**에서 배포 소스를 선택합니다. 보통 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.
3. 제공된 Pages 주소에서 `index.html`을 확인합니다.

모든 내부 메뉴는 상대 경로를 사용하므로 사용자/프로젝트 페이지 양쪽에서 작동합니다. 사이트 주소가 `/` 하위 경로에 있어도 별도 빌드 설정이 필요 없습니다.

## 사진과 정보

사진은 외부 Wikimedia Commons `Special:FilePath` 주소에서 불러옵니다. 따라서 페이지를 표시할 때 인터넷 연결이 필요합니다. 사진별 저작자·라이선스와 원문 링크는 `sources.html`에 기록했습니다. 재배포 전에 개별 원본 페이지의 최신 사용 조건을 확인해 주세요.

여행지 설명은 홋카이도 공식 관광 사이트와 각 지역 관광협회 자료를 바탕으로 짧게 요약했습니다. 최신 뉴스는 2026-11-06 확인 당시의 공지를 정적으로 정리한 것이어서 자동 갱신되지 않습니다. 여행 전 원문에서 운행·영업 정보를 다시 확인하세요.
